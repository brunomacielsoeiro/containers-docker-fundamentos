# Containers com Docker

> 🎓 **Contexto acadêmico**  
> Este projeto foi desenvolvido como atividade prática de estudos sobre
> containers utilizando Docker, com o objetivo de compreender a criação,
> execução e gerenciamento de aplicações em ambientes isolados.

---

## 🎯 Objetivos

- Entender o conceito de containers
- Aprender Docker na prática
- Criar e executar imagens
- Executar aplicações isoladas em containers

---

## 📦 Conteúdo

- Conceitos de Docker
- Comandos básicos
- Dockerfile
- Execução de aplicação em container

---

## 🧠 Aplicação prática

Este projeto inclui uma aplicação simples em Python executada dentro de um container Docker.
